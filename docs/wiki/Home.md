# Documentation

Start with the [project overview](../../README.md) for a single-file example.
These files are the reviewed source for the
[GitHub wiki](https://github.com/nd-vs/whisper-srt-aligner/wiki). Links also work
inside the repository, keeping documentation available alongside the code.

- [Installation](Installation.md): Windows, Linux, macOS, CPU and NVIDIA setup.
- [Usage](Usage.md): languages, audio tracks, seasons, caches, MKV output.
- [Reports and accuracy](Reports-and-accuracy.md): what to review and known limits.
- [Troubleshooting](Troubleshooting.md): dependencies, models, and timing problems.
- [Architecture](Architecture.md): recognition and alignment pipeline.
- [Development](Development.md): tests, packaging, and the reproducible demo.

This is a command-line tool. There is no desktop GUI or standalone Windows
executable in this release.
