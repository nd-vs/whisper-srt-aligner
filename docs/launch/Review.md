распознавание падало ещё до обработки речи. В зависимости добавлено `av<19`;
это исправление первого запуска, а не изменение алгоритма.

## Экспорт wiki

GitHub wiki — отдельный Git-репозиторий. После одобрения её нужно включить/создать
первую страницу, затем перенести локально экспортированные страницы.
`scripts/export_wiki.py` переписывает ссылки для wiki, но ничего не публикует.
До этого README ссылается на рабочие страницы внутри основного репозитория.
