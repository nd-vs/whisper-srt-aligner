# First-run study — prepared, not conducted

Recruit 3–5 volunteers after owner approval. No invitations have been sent and no
external-user results exist. The maintainer's successful run is not a substitute.

## Invitation draft

Could you try a small subtitle-timing tool from its README and tell me where it is
confusing? You will need Python and FFmpeg, and the first run downloads a speech
model. Use the supplied short demo; sharing personal videos is unnecessary.
Please stop whenever you normally would and tell me what blocked you.

## Tasks (do not coach unless they ask)

1. Explain in your own words what the tool does and whether it fits your problem.
2. Install it from the source ZIP, using only the README/documentation.
3. Run the demo; find the output SRT and report; play the comparison.
4. Explain what an inferred or dropped line means and what you would do next.
5. Optionally try one file you own. Record difficulty selecting the right audio.

Ask for OS, Python version, CPU/GPU choice, installation time, first successful
command, errors, and the moment they would have abandoned the task. Ask whether a
file picker/installer would materially help; do not lead with a proposed GUI.

## What to decide afterward

- Repeated dependency/setup failures: prioritize an installer or bundled runtime.
- Setup succeeds but commands/file paths stop people: consider a minimal file-picker UI.
- Users can run it but cannot review uncertain lines: prioritize a better review flow.
- Few visitors: improve relevant demonstrations/distribution before expanding the UI.

This is qualitative feedback, not a statistically meaningful conversion experiment.
Record public Traffic views/unique visitors/clones before publication and again
after a comparable period, noting dates, repeat visits and potential automated traffic.
The owner's supplied baseline screenshot showed 4 unique visitors and 4 unique
cloners in its displayed 14-day window; neither count is proof of four human users.
